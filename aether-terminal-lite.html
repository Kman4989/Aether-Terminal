About & FAQ

About NettleWeb

The NettleWeb Project is a free, open-source, community-maintained project. It aims to provide every internet user a private and unrestricted web browsing environment, with the focus of liberty, privacy and community. We believe that it is incorrect to steal user data without their proper consent, and everyone deserves the right to do whatever they want.

The NettleWeb Website

The NettleWeb Website (nettleweb.com) is a free, open-source online community platform. It allows users to chat, watch videos and play games, without any privacy or censorship concerns. nettleweb.com is more than just a website, but a hub of creativity, socialization, and fun.

Frequently Asked Questions (FAQ)

Is NettleWeb free to use?

Yes, NettleWeb is completely free to use. All features within NettleWeb can be accessed with absolutely no charge.

Where can I find the source code?

NettleWeb, as a free, open-source project, has most of its source code published on the official GitHub and Gitea profiles. You can access it by following the links.

Note: Some parts of the project have not been released due to security concerns, we will release these parts once these issues have been resolved.

What are the rules for posting messages across the website?

NettleWeb aims to bring everyone a liberal, uncensored online social environment, so we are not willing to restrict our users freedom.

However as a basic requirement of building a healthy community, you are required to follow the rules below:

- No illegal contents - Posting any illegal or extreme contents publicly is strictly prohibited, as required by the law.

- No NSFW / adult-only contents - The NettleWeb community is inclusive to people at all age, so you are not permitted to post any explicit content which could be harmful to certain users.

- No over-advertising / repetitive messages - Do not post messages with the same content more than once. Although this is usually acceptable for reactions, attempts to fill the screen and prevent others from scrolling back to older messages are strictly prohibited. This includes the use of third-party clients for bypassing the rate limits or using automatic tools that slow down the server.

If you did not comply with the rules above while using the platform, you may receive content deletion, account suspension or a permanent restriction of a certain feature depending on the severity.

I have discovered contents that appear to violate the rules, how should I report them?

You can always report to the admins by following the 'report abuse' link in the footer. Attaching screenshots within your report could help us to better understand the case, especially when dealing with end-to-end encrypted contents.

Is NettleWeb designed for bypassing network restrictions?

No, NettleWeb is an online community platform or an internet hub with social features. It has its main focus on improving chat features and how they can be integrated with other features on the website. Although there is an unblосkеr in the apps page, it is a leftover from the legacy WhiteSpider project, which is not yet removed due to dependency breakage. It has not been updated and may be removed in the future. You should always comply with your network policies.

Why I can't give likes or post comments in the videos?

The NettleWeb Videos service currently acts as a crawler that collects data from other streaming sites. It does not store any video related data on its own. Until NettleWeb releases its own streaming platform, all videos will be view-only with no interactions allowed.

Upload Game

Notice

Your game will be reviewed by the administrators before becoming visible to the public. This process could take 3-5 days, or even longer in some cases. Certain infomration may be edited or deleted based on our needs.

If you are submitting a new game, please ensure that your submission meets the following requirements:

1. All information of the game are filled correctly.

2. The game is playable without depending on third-party resources.

3. The game is not duplicated with one that already exists on the site.

4. The game is not copyright-protected, or is explicitly allowed for redistribution.

If you are updating an existing game, please scroll down to see the instructions.


HTML5 Games

The game file must be a valid ZIP file with a file named exactly `index.html` inside. The file will be used as the game's entry. If your game need to be compiled, please do so before uploading as we only accept static HTML/JS/CSS files.

The game does not depend on any resources from any third-party domains. (Connecting to third-party hosts will be blocked by the website's CSP, which might result the game being rejected.)


Flash Games

The game file must be a valid SWF file.

The game must not contain a site lock, or any settings preventing it from running on other websites.

If the game depends on external files apart from the SWF, upload it in ZIP format as a HTML5 game with a tag 'flash'.


DOS Games

The game file must be a valid JS-DOS bundle. If you have a ZIP file, please convert it into a JS-DOS bundle via the DOS Zone Studio.


Other Emulator Games

Unfortunately, other emulator-based games, such as N64, NES, SNES, are not currently supported to be uploaded here. However you can play them with the game emulator under the 'apps' page.


Updating an existing game?

If you need to update an existing game, select the new game file and set the 'name' field to 'Update: [GAME NAME/ID]' (Example: 'Update: 1v1.lol'). You may leave other fields empty as they will inherit from the original game.

Please test the game to see if it can be played when embedded. Games that are not playable or does not comply with the website's CSP will be rejected.

Once you have tested the game and confirmed that it functions correctly, click the button below again to upload.
